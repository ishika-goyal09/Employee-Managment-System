#Employee Management System 👨‍💼

A full-stack Employee Management System built using the MERN stack to simplify and manage essential workforce operations such as employee records, attendance, leave management, and payslip generation.
The application includes role-based authentication and authorization for Admin and Employee users, allowing different users to access features according to their roles.

📌 Overview

The Employee Management System is designed to provide a centralized platform for managing employee-related information and daily workforce activities.
Admins can manage employee records, monitor attendance, handle leave requests, and generate payslips, while employees can access their personal information and manage their attendance and leave-related activities.

Features

 Employee record management

 Attendance management
 
 Leave management
 
 Payslip generation
 
 JWT-based authentication
 
 Role-Based Access Control
 
 Admin and Employee roles

Tech Stack

Frontend : React.js, JavaScript, HTML5, CSS3,

Backend: Node.js, Express.js, RESTful APIs, JWT Authentication,Role-Based Access Control

Database: MongoDB
